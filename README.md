# Комплаенс-карта санкций против России — версия 2.0

Сайт: https://luxtendebant-ux.github.io/Sanctions_map_v.2.0/

- `index.html` — карта (один самодостаточный файл; закрытые разделы зашифрованы).
- `map-data-open.json` — машиночитаемая выгрузка открытой части карты (те же данные, без закрытых разделов).
- `screen-index.json` — индекс официальных санкционных списков (OFAC SDN и non-SDN, ЕС, Великобритания, Канада, Швейцария) для проверки контрагента в разделе «Рабочее место СК»; собирается автоматически дважды в сутки из файлов регуляторов (`.github/workflows/screen-index.yml`, без ИИ). Дата каждого источника показывается в результате проверки.
- `screen-delta.json` — новые и исключённые записи списков за 45 дней (для ежедневной сверки контрагентов).
- `deadlines.ics` — контрольные даты карты для подписки в календаре: Google Календарь → «Другие календари» → «+» → «По URL» → `https://luxtendebant-ux.github.io/Sanctions_map_v.2.0/deadlines.ics`. Напоминания для подписанного календаря задаются в его настройках (например, «за 3 дня»).
